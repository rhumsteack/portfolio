INTÉRÊT

Impossible de passer à côté de l'IA aujourd'hui. Il s'agit d'un outil tellement puissant qu'il ouvre le champ des possibles. Forcément ça m'intéresse : que peut-on faire avec ? Comment ça marche ? RÉFLEXIONS

Les expérimentations présentées ici me servent surtout à tester ce que l'IA apporte concrètement : accélérer la réalisation d'un produit, mieux cibler les tests, ou rendre un prototype plus vite exploitable. L'important c'est d'essayer pour s'approprier l'outil et même à travers les suggestions de l'IA découvrir d'autres outils ou technologies.

Tutoriel rapide (MyBinder)

  1. Cliquer sur Lancer sur MyBinder et attendre l'ouverture complète de JupyterLab.
  2. Dans JupyterLab, menu Exécuter > Exécuter toutes les cellules (ou Run > Run All Cells) pour lancer le notebook complet.

Si MyBinder affiche ModuleNotFoundError: matplotlib, exécuter dans une cellule : %pip install -q matplotlib puis redémarrer le kernel.
